CONNECT YOUR WORK

Add an existing project

Use a local Layer Cache configuration for each project. To connect its Team Cache, configure your team's endpoint and sign in:

layercache setup \
  --config /path/to/project.json \
  --project github.com/your-team/your-project \
  --team-url https://your-team-cache.example.com \
  --non-interactive

layercache login --github-cli --config /path/to/project.json
layercache start --config /path/to/project.json

Restart the dashboard with one configuration per project:

layercache dashboard \
  --config /path/to/first-project.json \
  --config /path/to/second-project.json

A team administrator must provision the Team Cache and grant project access. Self-serve team creation and cloud runners are not available in this slice.
