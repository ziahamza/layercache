# Define cache identity, compatibility, and invalidation

Type: grilling
Status: open
Blocked by: 01, 02, 03, 05

## Question

Which parts of identity come from each client protocol, and which compatibility facts must Layer Cache add? Resolve project and repository identity, operating system, CPU architecture, target platform, runtime and toolchain versions, dirty source, configuration, negative results, mutable aliases, and invalidation ownership without pretending one universal key exists. Ensure reusable identity survives different absolute checkout paths, new worktrees, and replacement VMs without merging incompatible results.
